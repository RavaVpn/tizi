## 挑梯子只看三件事

1. **晚上高峰稳不稳**：白天人少，什么梯子都快。晚上八点到十一点大家都在用，挤不挤、掉不掉，这时候才看得出来。
2. **断了能不能自己回来**：没有梯子能保证永不断线。区别在于断了之后，是悄悄自动重连，还是每次要你手动点。
3. **出了问题有没有人管**：机场跑路、节点集体挂掉都不是新闻。用有正经售后的服务，出事时至少有地方问。

速度、节点数、价格都是次要的：你日常只会用那一两条线路，它稳不稳，参数表上看不出来。
